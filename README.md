# 💜 CicloCuidar

App **gratuito** de saúde da mulher. Funciona offline, não coleta dados
(tudo fica no aparelho) e tem código aberto.

## Como usar
Abra https://SEU-USUARIO.github.io/croclocuidar/ no celular e toque em
"Adicionar à tela inicial".

## Como contribuir
Veja as issues abertas, fork o projeto e envie um Pull Request.
